# 常见问题

## 页面无样式、按钮没反应

检查是否打开了 file:// 文件。必须启动服务，访问终端打印的 http://127.0.0.1:<port>，不能直接打开前端文件。

## 关闭后无法再打开

网页与进程是两回事。终端关闭、电脑重启或 Agent 停止服务后，需要重新运行 interview-sim web。端口可能改变，以新输出为准。

## 找不到 Skill / 缺少依赖

需要完整仓库并执行安装与 python scripts/install_skill.py；必要时重开 Agent 会话。

依赖装在 .venv 时，使用 .venv/bin/python .agents/skills/interview-sim/scripts/launch.py，或先激活环境再运行 interview-sim web。

## 端口占用

启动器自动尝试后续端口，使用输出的新地址即可。不要关闭未知用途进程。也可传 --port 指定首选端口。

## 回答已保存，但下一题没生成

本测试版的已知限制：连接失败可能让出题中断，暂时没有独立的重试入口。可从训练记录查看，选择仅结束，或分析已有记录。不要反复发送同一答案。

随后检查对话服务的网络、代理、地址、权限与额度。重新开始会创建新会话，不会接续原来的出题状态。

## 报告失败或超过预计时间

估计由题量与本机样本计算，不是完成期限。模型速度、网络与限流会影响耗时。

保留记录，检查分析连接后继续生成；已完成阶段可复用。更改材料、回答或分析模型连接后可能需要重新分析。尽量不要在报告运行时停止服务。

| 错误 | 优先检查 |
|---|---|
| 401 / 403 | Key、账号权限、模型是否开通 |
| 429 | 额度与频率限制 |
| 400 / JSON 错误 | 接口与 JSON 对象输出是否兼容 |
| Connection error / 超时 | 网络、代理、Base URL、服务可达性 |

## 麦克风或声音异常

检查浏览器和系统麦克风权限；先停止朗读再录音，避免录到扬声器声音。分段边界可能影响标点与重复词，发送前可修改。

TTS 持续变速、音调异常时检查采样率与音色 ID。首次音频有缓冲，但未验证全部设备，不能保证完全无卡顿。

## 文件上传失败

仅支持 DOCX，不支持旧 DOC；PDF 需有文本且未加密，扫描件可转图片。上限 12 MB，PDF 最多 60 页。

macOS OCR 需要 Swift / Vision；其他系统需要 Tesseract 及 chi_sim、eng 语言包，且尚未完整验收。

## 完全离线吗？能否公网使用？

不是完全离线，模型所需材料发送到配置的 API。不要将当前无多用户认证的服务开放公网、局域网或隧道；不要把个人数据目录当作静态资源发布。

## 反馈需要什么？

操作系统、Python / 浏览器版本、功能、模型协议、错误类别和复现步骤。截图先遮挡真实姓名、联系方式、公司敏感内容、简历与密钥。不上传原始 session、.env 或 config.json。
