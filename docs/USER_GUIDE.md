# 操作指南

## 创建岗位

在“准备面试”创建岗位，粘贴 JD 或导入文件；可让 AI 提取公司、城市、岗位、薪资、学历、职责和要求，再人工核对。

为每个岗位保存真实简历与训练目标。公司背景可补充已知业务、产品和客户信息；不会自动联网核实，也不是该公司的真实题库。

支持 TXT / MD / DOCX / 文本 PDF / PNG / JPG / WEBP，单文件不超过 12 MB。旧 DOC 不支持，图片 OCR 后请检查文字。

## 开始面试

选择岗位，再选择本次角色、性别对应声音与难度；不覆盖岗位预设。分析模型先建立题纲，随后进入第一题。公司材料、简历和实际回答参与追问，题纲并非严格固定顺序。

## 文字 / 语音回答

文字：输入后发送；Enter 发送，Shift+Enter 换行。

语音：

1. 允许本地网页和浏览器使用麦克风，点击开始录音。
2. 约每 4 秒更新一段转写，包含网络时间；停顿不停止，也不自动发送。
3. 自行结束录音，等最后片段完成。
4. 检查和修改转写草稿，再确认发送。
5. 失败片段可重试；刷新或关闭页面会丢失未提交录音与草稿。

单次录音上限 10 分钟。面试官声音可重听或停止；不使用语音可关闭自动朗读。

## 跳题

可选择原因并直接跳过。保存为“未回答”，报告中本题计 0 分，结合考察点给出训练建议，不从沉默推测心理状态。主动跳题与出题连接失败不同。

## 结束方式

- **仅结束并保存记录**：只在本机保存，不触发报告调用；之后可从训练记录打开并生成报告。
- **结束并生成报告**：分析已有记录，已经问出但未回答的当前题标记未回答。
- **继续面试**：取消结束操作。

未问出的题目不会凭空生成作答记录。有未发送文字时会提示先发送或自行清空，不会自动替你提交。

## 报告与重答

报告分批分析，再汇总；显示阶段与估计时间，估计不是承诺。完成阶段会保存，刷新可恢复查看，失败可继续生成。

核对逐题引用是否来自自己的回答。从“重答这题”针对一个缺口练习，保留多次作答。分数不能作为真实招聘筛选或能力认证。

导出 Markdown / JSON，或用“打印 / PDF”另存文件。报告可能含个人资料，不要原样贴进公开 Issue。
