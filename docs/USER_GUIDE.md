# 操作指南

## 创建岗位

在“岗位工作台”创建岗位，粘贴 JD 或导入文件；可让 AI 提取公司、城市、岗位、薪资、学历、职责和要求，再人工核对。

为每个岗位保存真实简历与训练目标。公司背景可补充已知业务、产品和客户信息；不会自动联网核实，也不是该公司的真实题库。

支持 TXT / MD / DOCX / 文本 PDF / PNG / JPG / WEBP，单文件不超过 12 MB。旧 DOC 不支持，图片 OCR 后请检查文字。

## 开始面试

岗位有两个入口：“准备这个岗位”先做可选的简历诊断、岗位要求分析和经历整理；“开始面试”直接选择已保存的简历版本，再选择本次角色、性别对应声音与难度，不覆盖岗位预设。两者最终进入同一套实战，详见 [岗位准备](PREPARATION.md)。

分析模型先建立后台题纲，随后进入第一题。公司材料、简历和实际回答参与追问，题纲并非严格固定顺序。现场只显示实际对话，不显示题纲、回答提示或分数；讲解与训练建议全部在面后。

出题与跳题使用同一份已问记录。动态追问归属原考察点，同一轮最多连续追问两次、不能重复同一追问重点；跳过后转向尚未覆盖的题纲。新题先经过重复检查再显示，明显重复会重新选择一次，再失败则使用尚未问过的题纲题。这个检查能拦截完全相同及高度近似的问题，不保证识别所有换一种说法的语义重复。

## 文字 / 语音回答

文字：输入后发送；Enter 发送，Shift+Enter 换行。

语音：

1. 允许本地网页和浏览器使用麦克风，点击开始录音。
2. 约每 4 秒更新一段转写，包含网络时间；停顿不停止，也不自动发送。
3. 自行结束录音，等最后片段完成。
4. 检查和修改转写草稿，再确认发送。
5. 失败片段可重试；刷新或关闭页面会丢失未提交录音与草稿。

单次录音上限 10 分钟。面试官声音可重听或停止；不使用语音可关闭自动朗读。

语音按识别服务返回的文字显示，不再做 AI 润色、删除口头重复或语气词，也不会在结束录音后额外调用对话模型改写。你仍可手动纠正识别错字，最后确认发送；未发送的文字和音频仅在当前页面，刷新前请先处理。

此前试用的“保真整理”已撤回，旧的自动整理偏好不再生效。历史记录若曾保存原文和整理版，仍保持原样，不删除也不重新改写。原始 ASR 也可能识别有误，报告只评价确认发送的文字，不能据此评价真实语速或现场流畅度。

回答已保存但下一题失败时，不要重复发送。点击明确的重试出题按钮；如果仍在生成中，可点击刷新当前问题，仅查询本地状态，不调用对话或朗读模型。刷新或重启后，会话从服务端的当前题恢复。

## 跳题

可选择原因并直接跳过。保存为“未回答”，报告中本题计 0 分，结合考察点给出训练建议，不从沉默推测心理状态。主动跳题与出题连接失败不同。

例外：重新生成报告时，能够明确识别为旧流程“动态题之后又出现同一道题纲题”的重复跳题会标注为系统重复，不再次扣分；原始记录不删除。模糊的相似题不擅自豁免，面后主动重答仍按实际作答计分。

## 结束方式

- **仅结束并保存记录**：只在本机保存，不触发报告调用；之后可从训练记录打开并生成报告。
- **结束并生成报告**：分析已有记录，已经问出但未回答的当前题标记未回答。
- **继续面试**：取消结束操作。

未问出的题目不会凭空生成作答记录。有未发送文字时会提示先发送或自行清空，不会自动替你提交。

## 报告与重答

报告分批分析，再汇总；显示阶段与估计时间，估计不是承诺。完成阶段会保存，刷新可恢复查看，失败可继续生成。

新报告将“简历质量”“首次面试表现”“最新重答表现”分开展示，重答只与同题首答比较。未诊断简历显示未评估；未问到的要求不计零分。旧版五维报告保留原口径并单独标记，详见 [评分规则](SCORING.md)。

核对逐题引用后，从“重答这题”针对一个缺口练习。只重答这一题，不会延伸普通题纲；刷新后仍回到该重答。提交或跳过后保存，原报告和首答保留，可明确生成新的复盘。分数不能作为真实招聘筛选或能力认证。

面试绑定岗位和版本且已结束时，可明确提取“面试素材”。这个操作调用分析模型，从保存的原回答摘录待确认事实，不能把报告示例当成经历。进入岗位准备核对来源，逐条确认、修改或拒绝；需要写进简历的内容仍由你编辑并保存新版本，下一次面试才使用新正文。仅结束保存不会自动提取或生成报告。

导出 Markdown / JSON，或用“打印 / PDF”另存文件。报告可能含个人资料，不要原样贴进公开 Issue。
